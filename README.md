# 샷 트레이서 (안드로이드) v0.4

폰 카메라로 골프 스윙을 찍으면 공이 날아간 궤적을 화면에 그려 주는 앱입니다.
모드는 두 가지이고, 분석 엔진은 둘이 같이 씁니다.

| 모드 | 동작 |
|---|---|
| 실시간 촬영 | 미리보기 화면에서 공을 탭하고 스윙합니다. 날아가는 공을 점으로 바로 추적하고, 추적이 끝나면(보통 1초 안팎) 예측 궤적을 빨간 선으로 그립니다. |
| 저장된 영상 분석 | 갤러리 영상을 고르고, 공이 놓여 있는 장면에서 공을 탭한 뒤 분석합니다. 영상을 재생하면서 궤적이 따라 그려집니다. |

## 빌드 방법
1. Android Studio(Ladybug 이상)에서 이 폴더를 엽니다(File → Open).
2. Gradle 동기화가 끝나면 폰을 USB로 연결합니다. 폰에서는 개발자 옵션의 USB 디버깅을 켜 둡니다.
3. ▶ Run 버튼을 누릅니다. (최소 안드로이드 9)

## 촬영 요령 (정확도에 가장 큰 영향)
- 폰은 **반드시 고정**하세요. 삼각대나 거치대를 쓰면 됩니다. 손으로 들고 찍으면 화면 전체가 움직여서 공을 못 찾습니다.
- 골퍼 **뒤쪽에서 목표 방향**으로 찍고, 공이 화면 아래쪽 1/3 지점에 오게 하세요.
- 저장된 영상은 **슬로모션(120/240fps)** 일수록 정확합니다.
- 공이 맑은 하늘이나 나무 같은 배경과 대비될수록 오래 추적됩니다.

## 구조
```
app/src/main/java/com/seonbong/shottracer/
  engine/TracerEngine.kt   임팩트 감지, 공 추적, 궤적 피팅(공통 엔진, 안드로이드 의존성 없음)
  engine/ShotSession.kt    샷 1회 상태 머신(대기→추적→완료/실패)
  ui/LiveActivity.kt       실시간 모드 (CameraX)
  ui/GalleryActivity.kt    갤러리 모드 (MediaMetadataRetriever + VideoView)
  ui/TraceOverlayView.kt   궤적 그리기
  ui/FrameConvert.kt       카메라/영상 프레임 → 640px 흑백 프레임
prototype/                 같은 알고리즘의 Python 버전과 가상 영상 테스트
```

## 알고리즘 요약
1. **임팩트 감지**: 탭한 공 주변 영역이 처음 모습과 달라지면 임팩트로 판단합니다.
2. **공 추적**: 세 프레임 차분으로 움직이는 작은 점을 찾고, 예측 위치 근처에서 가장 가까운 것을 고릅니다.
   - 초기에는 "티보다 위, 공과 같은 밝기 방향" 조건으로 클럽과 몸을 걸러 냅니다.
   - 공이 멀어져 화면에서 느려지면 프레임 간격을 자동으로 늘려 계속 잡습니다.
3. **궤적 피팅**: 원근 투영과 공기저항을 반영한 탄도 모델로 맞춥니다.
   공이 0.3~0.5초만 보여도 나머지 비행(정점, 낙하)을 예측해서 그립니다.

## 변경 이력
- v0.4: 실사용 피드백 반영 — ① 탭 위치를 실제 공 중심으로 자동 보정 ② 클럽이 공 옆에서 움직여도(왜글·백스윙) 임팩트로 착각하지 않고, 공 자체가 사라질 때만 임팩트 ③ 공 대신 클럽을 따라가던 문제 수정: 티에서 일직선으로 멀어지는 물체만 공으로 인정 ④ 흐린 공 잔상 인식 ⑤ 오감지 시 자동 재대기
- v0.3: 화면 이탈 시 카메라·분석 안전 처리, 엔진 단위 테스트, GitHub 자동 APK 빌드
- v0.2: 임팩트 시각 추정 안정화, 프레임 변환 고속화(cropRect 반영), 미리보기·분석 화면 영역 일치(ViewPort), 갤러리 VFR 실제 타임스탬프 사용, 프레임 수 메타데이터 누락 대응, 추적 버퍼 재사용

## 현재 한계 (다음 단계 후보)
- 실제 기기와 영상으로는 아직 테스트하지 않았습니다. 가상 영상 테스트만 통과한 상태라 실제 영상으로 값을 조정해야 합니다.
  조정할 값: `diffThr`, 공 크기 추정 `ballR`, 착지 지점 `landingFraction`.
- 실시간 모드는 CameraX 기본 분석 속도(30~60fps)로 동작합니다. 240fps 고속 촬영은 Camera2 고속 세션을 따로 구현해야 합니다.
- 궤적을 입힌 영상을 파일로 저장하는 기능은 아직 없습니다. 지금은 화면 녹화로 대신하세요.
- 공이 화면 밖으로 나가거나 배경이 복잡하면 추적이 일찍 끊길 수 있습니다.
